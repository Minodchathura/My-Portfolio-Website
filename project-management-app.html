Project

Management App

C#Windows FormsSQL Server

A desktop application for creating and managing customer accounts, built with C# and Windows Forms and connected to a SQL Server database.

View on GitHub All Projects

Overview

Problem / Goal

To practise building a complete desktop application that registers users, stores their data in a database and lets them be managed through a clear interface.

My Contribution

Designed the Windows Forms screens and implemented all features myself, including the SQL Server connection for storing, retrieving and updating customer information.

Tools Used

C#Windows FormsSQL Server

Key Features

  • User registration (sign up) and login
  • Dashboard showing the total number of accounts and users
  • Create new accounts with personal details and account type
  • Search, view, update and delete accounts
  • Deposit money and check the current balance
  • Customer area with account balance, profile and change password
  • Customer data stored and retrieved from SQL Server
