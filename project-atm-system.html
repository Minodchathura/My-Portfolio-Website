Project

ATM Banking System

C

A console-based ATM program written in C with account number and PIN verification for multiple accounts.

View on GitHub All Projects

Overview

Problem / Goal

To practise structured programming in C by simulating how an ATM verifies a user and handles basic transactions.

My Contribution

Wrote the whole program independently using functions, arrays, conditional statements and loops to manage multiple accounts.

Tools Used

C

Key Features

  • Customer selection by card (k, s, i or l) with a personal greeting
  • PIN verification, with an incorrect PIN rejected and asked again
  • Balance inquiry (option 2)
  • Cash withdrawal with the updated balance shown (option 1)
  • Support for multiple accounts
  • Structured data handling with arrays
