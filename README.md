# Minod Chathura - Portfolio Website

Personal portfolio website made for the **TICT2252 System Analysis & Design** individual assignment
(University of Vavuniya, BICT Honours).

- Live website: `ADD YOUR GITHUB PAGES / NETLIFY LINK HERE`
- GitHub repository: `ADD YOUR REPOSITORY LINK HERE`

## Pages and sections

| File | Content |
| --- | --- |
| `index.html` | Home, About Me, Education (with certificates), Skills, Projects, Experience & Activities, CV, Contact & Links |
| `project-management-app.html` | Management App (C#, Windows Forms, SQL Server) |
| `project-atm-system.html` | ATM Banking System (C) |
| `project-file-manager.html` | Python File Management App (Python) |
| `style.css` | All styles (plain CSS, responsive) |
| `script.js` | Menu, typing effect, scroll fade-in, lightbox, contact form validation |
| `assets/` | Profile photo, CV (PDF), certificates and project screenshots |

## Technology

HTML5, CSS3 and plain JavaScript. No framework, no backend, no database.

## How to run

Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## How to publish (GitHub Pages)

1. Push this folder to a GitHub repository.
2. Repository **Settings > Pages**, choose the `main` branch and `/ (root)` folder.
3. Wait a minute, then open the link GitHub shows.
